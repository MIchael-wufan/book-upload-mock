# mock-图书审核

零依赖的图书审核交互原型，用于展示用户上传图书的 AI 审核结果和人工审核流程。

## 启动

在本目录执行：

```bash
python3 -m http.server 4173
```

然后访问 <http://127.0.0.1:4173/>。

## 演示内容

- 图书审核列表、四种审核状态、AI 未通过与待人工审核数量统计、拒绝备注、筛选和分页样式
- 审核通过入库后展示可跳转的新图书 ID
- 审核列表将版本、地区、学科、年级、册次以标签形式归入图书信息列：第一行版本和地区，第二行学科、年级和册次；并展示上传者 ID/名称等字段
- 审核详情与当前审核状态
- 默认展示 16 张答案缩略图，桌面端每行 5 张
- 单一图片编辑会话：点击“编辑图片”后可拖拽调整图片顺序，并可点击单图进行原图预览、左右旋转 90°、重置方向、裁切和删除；未进入编辑时仅可预览
- 点击“完成编辑”统一保存本次图片调整；点击“取消编辑”则回退本次会话内的排序、删除、旋转和裁切等全部图片改动
- 答案图片通过原图上的可拖拽裁切框进行裁切，支持移动裁切区域和拖动四角缩放，并同步到缩略图和原图预览
- 待人工审核任务支持修改图书名称、版本、册次、年级和学科；版本和册次通过下拉列表选择，ISBN 和地区仅展示不可编辑
- 编辑模式下拖拽排序
- 人工审核详情不展示 AI 审核通过文案和分数
- 详情页标题栏右侧直接进行通过/拒绝审核；点击拒绝后在弹窗中填写必填审核备注

所有数据和图片均在浏览器本地模拟，不连接真实服务。
