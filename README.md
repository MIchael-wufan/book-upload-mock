# mock-图书审核

零依赖的图书审核交互原型，用于展示用户上传图书的 AI 审核结果和人工审核流程。

## 启动

在本目录执行：

```bash
python3 -m http.server 4173
```

然后访问 <http://127.0.0.1:4173/>。

## 演示内容

- 图书审核列表、四种审核状态、AI 未通过与待人工审核数量统计、拒绝备注、筛选和分页样式
- 年级、学科、地区、上传者 ID/名称等字段
- 审核详情与 AI 初审结果
- 默认展示 16 张答案缩略图
- 原图预览、上一张/下一张、左右旋转 90°、重置方向、删除和前后移动
- 编辑模式下拖拽排序
- 通过/拒绝审核及状态回写演示

所有数据和图片均在浏览器本地模拟，不连接真实服务。
